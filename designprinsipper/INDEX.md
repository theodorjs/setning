# Mine designprinsipper

Oppslagsverk for designvalg på tvers av nettsidene mine. Ett dokument per prosjekt. Hvert dokument har frontmatter med tags fra [[_tags]].

## Slik bruker du dette i et nytt prosjekt

1. Les `_tags.md` for å se vokabularet.
2. Finn prosjektene nedenfor som ligner på det nye, ut fra sidetype, funksjon, målgruppe og enhet.
3. Les de relevante dokumentene. Start med seksjonene «Kjerneprinsipper» og «Overførbarhet».
4. Ta med prinsipper merket Universell eller sidetype som passer. Tenk gjennom de som er merket Kun dette prosjektet før du bruker dem.
