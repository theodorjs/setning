# Tags for designprinsipper

Felles vokabular for alle prosjektdokumentene i denne mappen. Les denne filen før du tagger et nytt prosjekt.

## Regler

- Gjenbruk eksisterende tags. Legg til en ny bare hvis ingen passer.
- Små bokstaver, kebab-case, norske ord. Unntak: etablerte tekniske navn (pwa, react).
- Maks 3 til 6 tags per kategori i hvert dokument.
- Ny tag: legg den inn under riktig kategori nedenfor med en linje om hva den betyr, og hold listen alfabetisk.
- Ikke lag synonymer. Finn eksisterende tag først (f.eks. «mobil», ikke «telefon» eller «mobile»).

## sidetype (hva siden er)

- bruksanvisning: forklarer hvordan noe brukes, trinn for trinn
- dashboard: oversikt over tall eller status
- landingsside: presenterer én ting og leder til én handling
- nettbutikk: viser og selger produkter
- oppslagsverk: samling av innhold man slår opp i
- portal: samleside som leder videre til flere ressurser
- portefolje: viser frem eget arbeid
- skjermvisning: vises på storskjerm eller veggskjerm, lite eller ingen interaksjon
- spill: lek, quiz eller konkurranse
- verktoy: løser en avgrenset oppgave med input og output

## funksjon (hva brukeren gjør)

- avlese: ser på informasjon som oppdateres uten at brukeren gjør noe
- lese: tar inn lengre tekst
- lære: skal forstå eller huske noe
- navigere: finner frem i mye innhold
- presentere: viser frem for andre
- registrere: legger inn data
- sammenligne: veier alternativer mot hverandre
- sla-opp: finner ett konkret svar raskt
- spore: følger utvikling over tid

## informasjonstetthet

- lav: ett budskap eller én handling per skjerm
- middels: flere grupper, tydelig hierarki
- hoy: mye samtidig, brukeren skanner

## stemning

- noktern

## teknologi

- pwa
- react
- statisk-html
- vanilla-js

## fargemodus (lyst og mørkt tema)

- lys: bare lys modus
- mork: bare mørk modus
- lys-og-mork: begge, med bryter eller automatisk valg etter systemet

## fokus (designområder dokumentet dekker grundig)

Brukes for å finne dokumenter som går i dybden på ett område, selv om siden er av en annen type.

- datavisualisering: diagrammer, kategoripaletter og legender
- fargesystem
- ikonbruk
- interaksjon
- motivasjon: poeng, streak, belønning og tilbakemelding som holder brukeren i gang
- navigasjon
- typografi
- utskrift: papirutgaver, sidestørrelser og lesbarhet i svart-hvitt
